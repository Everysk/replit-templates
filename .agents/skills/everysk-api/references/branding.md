# Everysk Brand Guidelines

2026 brand identity governing all Everysk-related outputs — institutional credibility, capital markets expertise, visual identity, and voice.

## Brand Essence

**Core Positioning:** More than software—Everysk generates scalable efficiency through an ever-evolving partnership.

**Brand Promise:** A sharper, more mature version of Everysk that maintains its core essence while clearly communicating expertise and building trust easily.

**Key Themes:**
- Layered capabilities
- Assets beyond the platform
- Where AI meets precision
- Partnership journey
- Showcase proven results

## Priority Hierarchy

When generating Everysk content, optimize in this order:
1. Capital markets credibility
2. Operational clarity
3. Automation & AI differentiation
4. Visual and tonal consistency
5. Creativity (last)

**Governing principle:** If conflict exists between stylistic creativity and brand accuracy, brand accuracy wins.

## Brand Positioning (Canonical)

Everysk is the industry standard for AI-embedded workflows built for Investment Operations, delivering a digital investment workforce through no-code workflows, pre-built financial robots (hundreds of specialized robots), agentic AI, and generative AI.

**Primary Headline:** "AI-embedded workflows built for Investment Operations"

**Everysk is:**
- Purpose-built for capital markets (front, middle, and back office)
- The backbone of industry leader's operations
- Designed for institutional scale, auditability, and precision
- The engine behind investment operations
- An ever-evolving partnership

**Everysk is not:**
- A generic automation platform
- A horizontal AI tool

## AI Positioning Rules (Mandatory)

### Agentic AI
**Positioning:** "Natural Language to Execution" — Operate all systems through natural language

**The Three Phases:**
1. Understanding
2. Reasoning
3. Planning

**Architecture:**
- User prompt → LLM + MCP Orchestration → Agentic Layer → Outputs (Analyses, Alerts, Reports, Emails)
- Everysk MCP + 3rd Party MCPs integration

**Key Differentiator - Agentic AI + Workflow Automation:**

| Workflow Automation | Agentic AI |
|---------------------|------------|
| Structured Triggers, Formatted Data | Natural Language |
| Predefined Rule Base | Adaptive Goal-Oriented |
| Within Workflow | Persistent, Platform-Wide |

**Approved phrasing:**
- "Agentic AI that executes multi-step investment workflows"
- "AI agents that coordinate compliance, reporting, and alerts"
- "AI Agents understand goals, plan steps, retrieve data, execute workflows"
- "Natural language to execution"

**Disallowed:**
- "Smart assistant"
- "AI helper"
- "Chatbot experience"

### Generative AI
- GenAI is used for outputs, not control logic
- Focus on: Portfolio narratives, risk commentary, regulatory reports, client-ready summaries, Python code generation
- Never position GenAI as replacing human judgment or making discretionary investment decisions

## Voice & Language

### Always Do
- Use domain-specific capital markets language (alpha generation, liquidity crunch, intraday alerts)
- Quantify outcomes where possible (time saved, errors eliminated, ROI)
- Speak in operational terms (workflows, execution, controls)
- Maintain professional, institutional tone
- Emphasize automation as leverage and precision
- Reference partnership and collaboration
- Use "ever-evolving" theme

### Never Do
- Use consumer SaaS language ("delightful", "magic", "easy wins")
- Overpromise returns or alpha
- Use vague AI hype ("powered by cutting-edge AI")
- Anthropomorphize the platform
- Oversimplify complex financial concepts

### Tone by Context
- **Marketing:** Confident, authoritative, results-driven, mature
- **Product/Technical:** Clear, precise, technical yet accessible
- **Sales/Proposals:** Position as infrastructure and partnership, not just a tool; emphasize leverage
- **Client Communications:** Professional, partnership-oriented, solution-focused

## Visual Identity (2026 Brand Update)

### Color Palette (Mandatory)

**Primary Colors:**

| Name | Hex | Usage |
|------|-----|-------|
| Black | #000000 | Primary background, text |
| White | #FFFFFF | Primary text on dark, backgrounds |
| Orange | #F2703B | CTAs, key emphasis, brand accent (refined from #FF832A) |

**Secondary Colors:**

| Name | Hex | Usage |
|------|-----|-------|
| Soft Gray | #A49F8C | Primary neutral, panels, backgrounds |
| Off White | #ECEBE7 | Light backgrounds, cards |
| Ever Blue | #C9DDE8 | Data, analytics, technical highlights (softened from #86E9FF) |
| Soft Black | #313131 | Secondary dark surfaces |

**Color Evolution Rationale:**
- Orange refined to more muted, closed tone (#F2703B) for improved contrast and maturity
- Blue softened (#C9DDE8) for calmer presence and accessibility
- New neutral tones (Soft Gray #A49F8C, Off White #ECEBE7) bridge orange and blue, adding character while maintaining clean base

**Rules:**
- Never introduce new accent colors
- No gradients or playful palettes
- Maintain high contrast for accessibility
- Orange is for emphasis only, not overused
- Neutrals support AI messaging with stability and security

### Typography (Mandatory)

**Three-Font System:**

| Font | Usage | Notes |
|------|-------|-------|
|Playfair Display | Titles, Numbers, Headlines | Display Type - serif, elegant |
| Space Grotesk | Subtitles, Buttons, UI Labels | Sans-serif, technical |
| DM Sans | Body Text, Paragraphs | Sans-serif, readable |

**Hierarchy:**
- H1/Display: Playfair Display
- H2/Subtitles: Space Grotesk
- Buttons/Labels: Space Grotesk (uppercase for labels)
- Body: DM Sans
- Small text: DM Sans

### Logo & Brand Mark

**Primary Logo:** "everysk" wordmark in lowercase, but use the logo file if you have it. 
**Brand Mark:** Angular bracket icon in square frame (⟨ symbol stylized)
**Logo Placement:** Top-left on web, prominent on materials
**Brand Mark Usage:** Can be used standalone on swag, favicon, app icons

### Imagery Style

**Visual Treatment:**
- Stipple/halftone texture effect on photographs
- Black and white base imagery with orange accent overlays
- Mountain landscapes and city skylines (representing scale, achievement, global reach)
- Silhouette figures (representing the human element in automation)
- Abstract flowing lines representing connected workflows

**Approved Image Themes:**
- Mountains and peaks (achievement, scaling new heights)
- City skylines (global finance, institutional markets)
- Clouds and sky views (elevated perspective, clarity)
- Human silhouettes with stipple effect (partnership, human-AI collaboration)
- Abstract workflow diagrams with connecting nodes

**Image Treatment:**
- Apply stipple/halftone texture to photographs
- Use black and white as base
- Overlay orange (#F2703B) for accent areas
- Use Ever Blue (#C9DDE8) for data visualization areas

### Icons

**Robot/Feature Icons:**
- Rounded square containers with dark backgrounds
- White or orange icon symbols
- AI-enabled features marked with "AI" badge in top-right corner
- Consistent stroke weight across icon set

**Decorative Icons:**
- Orange geometric shapes (squares, rectangles) with blur/glow effects
- Used for abstract concepts and transitions
- Layered overlapping shapes suggesting depth and connection

### Layout Principles

- Clean, generous whitespace
- Dark mode preferred for hero sections and product displays
- Light mode (Off White #ECEBE7) for content-heavy sections
- Dot grid patterns as subtle background texture
- Asymmetric layouts with strong typography
- Connected workflow diagrams as key visual element
- High contrast for accessibility
- Design for institutional users, not consumers

## Content-Specific Directives

### Marketing Content
- Lead with outcomes, not features
- Anchor claims in operational reality
- Assume sophisticated financial audience
- Use Problem → Workflow → Automation → Outcome structure
- Emphasize partnership and evolution themes

### Product & Technical Content
- Precise, structured, unambiguous
- Favor clarity over persuasion
- Include operational context
- Reference robot library and workflow capabilities

### Sales & Proposals
- Emphasize automation as leverage, not replacement
- Position Everysk as infrastructure and partnership
- Quantify operational improvements
- Use social proof (BlackRock, Thomson Reuters, XP Inc., Addepar, OpenFin logos)

### Website & UI Generation
- Default to dark mode for hero sections
- Light mode (Off White) for content sections
- Use Season Mix for headlines
- Space Grotesk for UI elements
- DM Sans for body text
- Apply Everysk color palette strictly
- Include dot grid subtle backgrounds
- Feature workflow diagrams prominently

### Social Media & Digital
- Consistent use of brand mark
- Orange accent on key messaging
- Stipple texture on imagery
- Professional, institutional tone
