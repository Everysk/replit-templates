# Agent Skills (.agents/skills/)

Skills bundled with the template for AI agents working in this codebase.

## MANDATORY (per replit.md)
- **everysk-api** (`everysk-api/SKILL.md`) — Everysk SDK, REST API, branding, worker patterns
  - References: api-reference.md, branding.md, core.md, sdk-engines.md, sdk-entities.md, server.md, worker-patterns.md

- **ui-ux-pro-max** — Full design system with CSV data (colors, icons, charts, typography, stacks)

- **web-design-guidelines** — Web design reference

## Development
- **tdd** — TDD enforcement: Red→Green→Refactor cycle, co-located test files, deploy gate (`npm test` must pass). Stack: Vitest + Testing Library + MSW.
- **vercel-react-best-practices** — 50+ React performance rules (rendering, rerenders, async, bundles, JS)
- **vercel-react-native-skills** — React Native performance rules
- **systematic-debugging** — Root cause tracing, test pressure, defense in depth
- **browser-use** — Browser automation for agents
- **agent-tools** — Replit CLI: authentication, running apps, app discovery

## Utilities
- **brainstorming** — Brainstorming workflow
- **find-skills** — Skill discovery
- **pdf** — PDF manipulation with Python scripts
